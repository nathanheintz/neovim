# Lazygit Keyboard Shortcuts Cheatsheet

## Basic Navigation
- `?` - Show help menu
- `q` - Quit/close Lazygit
- `PgUp/PgDown` or `{/}` - Scroll through panels
- `Tab` - Switch between panels
- `h/j/k/l` - Navigate within panels (vim-style)

## Common Git Operations
- `c` - Commit changes
- `p` - Push
- `P` - Pull
- `f` - Fetch
- `d` - View diff of file
- `s` - Stage/unstage file or hunk
- `a` - Stage/unstage all
- `b` - Create new branch
- `o` - Open file
- `e` - Edit file
- `m` - Merge/Rebase options

## Working with Commits
- `Space` - Checkout branch/tag/commit
- `g` - View commit history
- `A` - Amend last commit
- `C` - Copy commit hash
- `r` - Refresh the UI
- `z` - Undo (pop stash)
- `R` - Refresh file list

## Stashing
- `S` - Stash changes
- `Shift+S` - View stash list
- `a` in stash list - Apply stash
- `d` in stash list - Drop stash

## Advanced Features
- `Ctrl+r` - Recent repositories
- `Ctrl+p` - Custom command panel
- `Ctrl+o` - Open config file
- `Shift+R` - Reset to commit
- `Shift+X` - Discard changes

## Branch Management
- `n` - Create new branch
- `Space` - Checkout branch
- `d` in branches panel - Delete branch
- `m` in branches panel - Merge into current branch
- `r` in branches panel - Rebase onto selected branch
